# v0.10.143 release notes

English | [简体中文](v0.10.143_ZH.md)

Release date: 2026-10-13. Status: formal release. The v0.10.116 extension was listed in the EDA marketplace as of 2026-10-12; v0.10.143 has been submitted to the marketplace and is currently under review; the public listing may remain on the previous version until approval.

This release updates component footprints and properties in place, with a read-only plan followed by execution and per-item readback. It also includes the accumulated extension and companion-skill updates since v0.10.116. The main extension package and the English-first skill package are separate downloads.

## Highlights

- `schematic.getComponentUpdatePlan` previews requested footprint and property changes. `schematic.updateComponents` executes the complete plan and verifies each item. The normal path preserves the existing schematic component identity rather than deleting and replacing it.
- The v0.10.143 isolated-project acceptance completed batch property updates and changed a connected resistor from 0402 to 0805. The requested attributes and footprint persisted after save, close, and reopen; component identity, position, symbol, and wires were retained.
- Selected larger-MCU fanout samples and a separate copper-fill readback path have historical isolated-project evidence. That evidence applies to the recorded samples and objects, not every geometry shape, PCB, or full MCU workflow. Inspect each current plan and resulting geometry.
- `module.*` commands proxy a separately installed module-reuse extension. That companion is not included in or published as part of this extension package; its available operations depend on the companion installation.
- The companion AI skill is English-first. Chinese remains available inside the same skill directory as a fallback.

## Verification and limits

The v0.10.143 normal component-update path passed in an isolated EDA project, including a real footprint change and save/close/reopen readback. The stale footprint-name repair fallback was not triggered in this session; it has regression evidence only. This release session did not synchronize the component change to PCB. Separate PCB import evidence from v0.10.138 was manually confirmed and remains historical; it is not a v0.10.143 PCB-sync result.

Local component-update regression, TypeScript checks, targeted lint, diff checks, independent review, build, and package checks are recorded as passed in the project acceptance record. This does not establish that every extension command or scenario passed in a real EDA host, nor that the EDA marketplace approved v0.10.143. A formal GitHub release does not imply marketplace acceptance.


For this publication, TypeScript checks, the build, and 16 relevant regression suites passed. An outdated bridge-owner test mock was updated to export the newly added component-update module; this is a test-only change. The plugin runtime was compared with the verified v0.10.143 candidate and is identical outside embedded publication metadata and build module labels. The SDK framework is 1.6.27 and the installed API type definitions are 0.4.26. No dependencies were upgraded.
