# v0.20.1 release notes

English | [简体中文](v0.20.1_ZH.md)

Release date: 2026-10-16. Release type: formal GitHub release, not a prerelease. The Chinese EDA marketplace package is prepared for the user to upload; marketplace upload and approval are pending.

## Changes

- Removed the extension's `cbb.*` and `module.*` command namespaces. The independent module-reuse extension remains a separate project and is unchanged.
- Reorganized the companion skill around schematic and PCB task frequency. English remains the primary skill; Chinese is the fallback in the same skill package.
- Updated the README and first-use guide to point to current skill pages and v0.20.1 release downloads. The v0.20.0 release remains available as historical release material.

## Verification status

TypeScript checking, the production build, and 15 existing regression suites passed. The runtime matches the original v0.20.1 candidate except for publication metadata and path labels. A total of 205 commands are registered; no `cbb.*` or `module.*` commands or duplicate command names are present. The extension has not been installed in a live EDA host, so host behavior remains unverified.
