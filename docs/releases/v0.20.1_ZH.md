# v0.20.1 正式发布说明

[English](v0.20.1.md) | 简体中文

发布日期：2026-10-16。发布类型：GitHub 正式发布，非预发布。中文嘉立创 EDA 市场包已准备好，由使用者上传；市场上传和审批状态待定。

## 更新内容

- 移除扩展对外的 `cbb.*` 与 `module.*` 指令命名空间。独立“模块复用”扩展仍是单独项目，本次没有修改。
- 配套技能按原理图和 PCB 任务频率重组。英文技能为主版，中文技能作为同一技能包内的备用说明。
- README 和首次使用指南已改为链接当前技能页面和 v0.20.1 下载；v0.20.0 发布内容继续作为历史版本保留。

## 验证状态

类型检查、正式构建和 15 组现有回归通过。运行程序与原始 v0.20.1 候选包对照，仅发布元数据和路径标记不同。实际注册 205 条指令；不含 `cbb.*`、`module.*` 指令，且没有重名。该版本尚未安装到真实 EDA 宿主，因此宿主行为尚未验证。
