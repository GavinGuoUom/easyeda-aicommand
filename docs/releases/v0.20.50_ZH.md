# v0.20.50 正式发布说明

[English](v0.20.50.md) | 简体中文

发布日期：2026-10-19。发布类型：GitHub 正式发布，非预发布。中文版嘉立创 EDA 市场包已重新提交，正在审核；当前公开上架版本仍为 v0.10.143。v0.20.50 的市场审核通过和上架状态尚未确认。

## 范围

v0.20.50 是基于 v0.20.49 核心的中文菜单和文档打包版，本版不新增核心写入操作。本文汇总 v0.20.11 至 v0.20.49 期间的修正和已明确边界。历史操作演示保留原始日期和版本，不作为 v0.20.50 宿主验收记录。

## 更新与操作边界

- 参数及结果处理增加无效参数预检、SDK 失败结果处理和写后读回。写入结果不明确时报告部分状态并停止依赖操作，不自动重试，也不把空结果当作成功。
- `routeTrack` 与 SES 线段输入在写入前检查；任一线段短于 1 mil 都会被拒绝。这是插件输入策略，不是 SDK 最短长度限制。
- 在线 `.epro2` 导入可用根 `project2.json` 的 `title` 派生工程名，并传递 `description`，保留空白和换行。原理图页复制仍保留；SDK 未提供可接受的新 UUID 时报告失败证据，不重试。离线导入及其他格式不因本项改变。
- `modifyPour` 改变铺铜网络或名称的请求会在写入前拒绝。自动布线 SES 回灌已禁用；检查外部布线结果须使用单独、明确的导入流程。
- EDA 4.1.78 下，需要 EDA 4.2 的 14 条指令已停用并在版本检查处拒绝。EDA 4.2 下的正向执行和持久性尚未验收。铜皮规则和焊盘热焊配置保留为只读诊断；单位或规则选择未知时不作推断。
- `pcb.connectComponentPadDirect` 因当前实测宿主无法可靠读回配置而暂时停用；兼容入口会在访问工程或 SDK 前拒绝调用。这不表示所有版本的 setter 均失效，也不代表小铜区未连接焊盘的问题已解决。

这些保护和分项检查不代表所有底层问题、几何结果、覆铜填充或持久性问题均已修复。覆铜接触和保存重开仍须分别核验。

## 验证状态

类型检查、正式构建和 31 组现有模拟回归通过。运行程序去掉构建路径标记后与市场候选版本一致，manifest 字段无差异。本发布包尚未重新安装到 EDA 宿主验证；EDA 4.2 下的正向行为尚未验证。
