# 生产文件操作要求

本文件维护制造文件导出、格式和平台核对的具体要求。
项目阶段验收、待实测清单和打样反馈由 hw-project 管理。
EDA导出命令按当前安装版帮助与技能入口的生产导出命令页执行。
平台页面检查不代表插件具备自动上传、下单或付款能力。

使用可用工具并按已有授权执行。
历史官方格式依据保留原核对范围，实际使用时核对当前平台要求。

## 制造与装配文件输出

### 确认输出版本

从同一已确认保存版本输出。
记录项目、板号、版本、日期和文件清单。
有不同装配方案时，注明本次采用的方案。
需要识别文件一致性时保存哈希。
不要混用不同版本的铜层、钻孔、BOM 和坐标。

具体格式及必需文件由目标厂商要求决定，通常核对以下类别：

| 类别 | 内容及检查 |
|---|---|
| PCB 制造 | 各实际铜层、阻焊、丝印、板框、钻孔/槽等所需制造数据。<br>逐层核对用途和完整性。 |
| 层叠与特殊工艺 | 订单需要的材料、层序、铜厚、板厚、阻抗及孔处理说明。<br>与实际设计一致。 |
| BOM | 位号、完整型号/料号、封装、数量、装配状态和可选方案。<br>关键参数须明确。 |
| 贴装坐标 | 位号、X/Y、单位、原点、旋转、顶底面。<br>与BOM和PCB逐项对应。 |
| 钢网 | 需要开钢网时检查顶底锡膏层。<br>不能用阻焊层替代钢网开口层。 |
| 装配说明 | 需要特别说明的方向、极性、不装件（DNP）、替代、手装和特殊工艺 |
| 测试/烧录 | 本项目要求的程序版本、接口、步骤、工装和判据 |

### 专业版 Gerber 输出

自定义导出时核对选中的图层、图元及相关选项。
官方说明“PCB 下单”按钮采用一键导出配置。
该按钮不采用自定义 Gerber 配置。
需要自定义配置时，先导出并检查 Gerber，再上传下单。

顶底 Paste Mask 文件用于开钢网。
钻孔加工文件与可选钻孔表、说明信息分别核对。
不要用钻孔表或仅供对照的钻孔图层替代钻孔加工文件。
自定义层及说明层不能默认视为制造层。
需要这些层参与生产时，明确其用途并与厂商确认。
依据：[专业版 Gerber 导出](https://prodocs.lceda.cn/cn/pcb/export-pcb-fabrication-file-gerber/index.html)。

### 独立检查

用独立查看器或厂商解析预览检查制造数据。
确认板框闭合且尺度正确。
确认层序正确。
核对孔槽位置及属性。
核对铜层、阻焊和丝印是否匹配。

BOM 与坐标按每个位号逐项核对。
手装件、DNP、机械件等差异项必须明确分类。
BOM 分组后仍需逐位号核对型号、数量和装配状态。
总数量相等不能证明逐项一致。

按导出工具和厂商要求核对坐标定义。
分别核对角度、原点和底面处理。
不统一给底面件镜像或增加固定角度。
重点复核连接器、二极管、IC、极性电容和自定义封装。

拼板、工艺边、定位孔和识别点按实际生产安排确定。
区分设计方与厂商各自负责的内容，避免重复添加或遗漏。

## 导入板厂与贴装平台

### 授权与订单身份

平台上传、资料共享、提交订单和付款按用户已有授权执行。
准备文件或完成设计不自动代表已授权对外上传、下单或付款。

核对厂商、项目、版本、数量和用途。
注明本次是验证性打样还是正式生产。
导入平台后的修改同样记录版本和影响。

### 裸板制造导入

- 检查平台识别的板尺寸、层数、板框、孔槽与上传文件一致。
- 核对材料、板厚、铜厚、表面处理、阻焊及实际需要的特殊工艺。
- 逐层对照图纸铜厚、检查采用的铜厚和订单铜厚。
- 三者不一致时，记录差异和处理状态。
- 订单铜厚改变后，重新检查受影响的载流、温升和阻抗要求。
- 更新订单参数不代表图纸层叠已经同步。
- 提交前确认差异已处理，未处理项按实际影响决定是否阻止提交。
- 核对导出图层与制造图层的对应关系、钻孔/槽、铜到边界和厂商提出的 DFM 问题。
- 平台默认选项不得悄悄替代设计条件。
- 缺工艺支持时明确冲突及可选处理方案。

### 嘉立创中国 SMT 导入格式

本节仅适用于嘉立创中国当前 SMT 文件导入流程。
项目 BOM 的完整记录要求与平台必填列分开处理。

- 官方 BOM 必需字段为 Comment、Designator、Footprint。
- Quantity 属于推荐字段。
- 填写 Quantity 时，应与该行有效位号数一致。
- 同一型号、规格及封装的器件可以合并位号。
- 坐标文件每个位号单独一行。
- 已填嘉立创料号时，平台会优先按料号匹配。
- 料号与参数冲突必须先查清。
- 本次不参与 SMT 的位号从待贴 BOM 和坐标中一致排除。
- DNP、手装等安排另保留在项目装配记录。
- 不依赖自定义备注自动传递生产要求。

依据：[嘉立创 BOM 与坐标格式规范](https://www.jlc.com/portal/server_guide_48022.html)。

- 坐标文件核对 Designator、Mid X、Mid Y、Layer、Rotation。
- Mid X/Y 采用器件中心坐标。
- 角度按器件轴心核对。
- 坐标单位优先使用 mm。
- 使用 mil 时，在数值后标明单位。
- Mid X 和 Mid Y 列名不附加单位。
- 记录导出时的坐标原点。
- Layer 使用 Top/T 或 Bottom/B。
- 板面按器件本体所在面填写。
- 特殊器件按实际贴装要求确认板面。
- 官方未限定坐标原点的位置。
- 本项目要求在导入预览中核对坐标与 PCB 的对应关系。

依据：[坐标格式解读](https://www.jlc.com/portal/q7i53182.html)。

专业版用于嘉立创打样时，不勾选底层坐标镜像。
底层角度镜像也不擅自启用。
该设置不能推广为所有 EDA 或所有贴装厂的规则。
导入后仍逐项核对底面位置、角度和极性。
依据：[专业版坐标导出](https://prodocs.lceda.cn/cn/pcb/export-pick-and-place-file/)。

### BOM 匹配和供料

- 逐项核对平台匹配的厂家完整型号、封装、关键参数及供应商料号。
- 检查匹配位号、数量、装配面、不装件和装配方案与缺料项目。
- 核对实际订单数量下的可供数量、装配支持、备料/损耗要求及费用。
- 历史库存和单价不作当前承诺。
- 平台推荐替代料需重新核对电气、脚位、封装、外围及制造影响。
- 名称相似不能证明可替代。
- 缺件、自购、客供、手装及不贴件分别记录。
- 确认最终 BOM 和坐标一致。

### 贴装预览

导入后对照 PCB 和封装图，逐位号核对型号、位置、板面、旋转和极性。
重点检查 1 脚、二极管方向、极性电容、连接器插接方向及平台无法可靠识别的器件。

不以自动匹配或报价结果代替检查。
发现偏移或旋转问题时，先核对坐标定义和库映射。
修正对应文件或平台项。
重新检查贴装预览。

### 提交前核对

确认上传版本、订单工艺、BOM/坐标、匹配料号、DNP、贴装方向、数量及尚未解决的制造或物料问题一致。
平台修改后，更新本地对应记录。
旧版本不能继续标为已批准生产。

未解决的真实制造或装配冲突阻止相关生产提交。
未完成的样机测试列为待验证。

### 烧录与测试交接

- 交付烧录焊盘和测试点的位置、板面、针序及网络表。
- 写清烧录器、供电方式、目标电压和必要的复位或启动操作。
- 写清测试项目、仪器、参考地和合格范围。
- 核对裸测试焊盘没有误入贴装 BOM 或坐标清单。
- 核对 0Ω 电阻的装配数量和默认状态。
- 测试中拆除或更换的 0Ω 电阻，交付前按方案恢复并检查。
- 样机验证包含实际烧录和探针接触检查。
