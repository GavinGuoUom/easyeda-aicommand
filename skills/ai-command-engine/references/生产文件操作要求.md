# Production File Requirements

This file maintains specific requirements for manufacturing-file exports, formats, and platform checks.
Use hw-project to manage project-stage acceptance, pending test items, and prototype feedback.
Follow the manufacturing-export command page linked from the skill entry point and the help for the currently installed version when using EDA export commands.
Checking a platform page does not mean the plugin can automatically upload files, place orders, or make payments.

Use available tools within existing authorization.
Historical official format references retain their original verification scope; check current platform requirements when using them.

## Manufacturing and Assembly Outputs

### Confirm the Output Version

Export from the same confirmed, saved version.
Record the project, board number, version, date, and file list.
If there are multiple assembly options, identify the option used for this output.
Save hashes when needed to identify file consistency.
Do not mix copper layers, drill files, BOM, and coordinates from different versions.

The target manufacturer determines the specific formats and required files. Common categories to check include:

| Category | Contents and checks |
|---|---|
| PCB fabrication | All required fabrication data, such as each actual copper layer, solder mask, silkscreen, board outline, and drill/slot data.<br>Check the purpose and completeness of each layer. |
| Stackup and special processes | Materials, layer order, copper thickness, board thickness, impedance, and hole-treatment notes required by the order.<br>Match them to the actual design. |
| BOM | Designators, complete model/part number, footprint, quantity, assembly status, and optional variants.<br>State key specifications explicitly. |
| Pick-and-place coordinates | Designator, X/Y, unit, origin, rotation, and top/bottom side.<br>Match each item against the BOM and PCB. |
| Stencil | Check the top and bottom paste layers when a stencil is needed.<br>Do not substitute solder-mask layers for stencil apertures. |
| Assembly instructions | Directions, polarity, do-not-populate (DNP) items, substitutions, hand assembly, and special processes that need specific instructions. |
| Test/programming | The program version, interface, steps, fixtures, and criteria required by the project. |

### Pro Edition Gerber Export

For a custom export, check the selected layers, primitives, and related options.
The official documentation says the “PCB Order” button uses a one-click export configuration.
That button does not use a custom Gerber configuration.
When a custom configuration is required, export and inspect the Gerber files before uploading them for an order.

Top and bottom Paste Mask files are used to make a stencil.
Check the drill fabrication files separately from optional drill tables and explanatory information.
Do not substitute a drill table or a drill layer intended only for reference for the drill fabrication files.
Do not assume custom or explanatory layers are manufacturing layers.
If those layers must be used in production, state their purpose and confirm with the manufacturer.
Source: [Pro Edition Gerber Export](https://prodocs.lceda.cn/cn/pcb/export-pcb-fabrication-file-gerber/index.html).

### Independent Inspection

Use an independent viewer or the manufacturer's parsed preview to inspect manufacturing data.
Confirm that the board outline is closed and has the correct dimensions.
Confirm the layer order.
Check hole and slot locations and attributes.
Check that copper, solder mask, and silkscreen match.

Check the BOM and coordinates item by item for every designator.
Clearly classify differences such as hand-assembled parts, DNP parts, and mechanical parts.
After grouping a BOM, still check each designator's model, quantity, and assembly status.
Equal total quantities do not prove item-by-item consistency.

Check coordinate definitions against the export tool and manufacturer requirements.
Check angle, origin, and bottom-side handling separately.
Do not apply mirroring to every bottom-side component or add a fixed angle correction universally.
Pay particular attention to connectors, diodes, ICs, polarized capacitors, and custom footprints.

Determine panelization, process rails, tooling holes, and fiducials according to the actual production arrangement.
Distinguish the responsibilities of the designer and manufacturer to avoid duplicating or omitting items.

## Import to Board Fabrication and Assembly Platforms

### Authorization and Order Identity

Platform uploads, sharing files, submitting orders, and payments must follow the user's existing authorization.
Preparing files or completing a design does not by itself authorize external upload, ordering, or payment.

Check the manufacturer, project, version, quantity, and intended use.
State whether this is a prototype for validation or formal production.
Record any changes made after importing into the platform, including the version and impact.

### Bare Board Fabrication Import

- Check that the dimensions, layer count, board outline, and holes/slots recognized by the platform match the uploaded files.
- Check the materials, board thickness, copper thickness, surface finish, solder mask, and any special processes actually required.
- Compare the copper thickness on the drawings, the thickness selected by the platform, and the thickness on the order, layer by layer.
- If they differ, record the difference and how it is being handled.
- If the order's copper thickness changes, recheck affected current capacity, temperature rise, and impedance requirements.
- Updating order parameters does not mean the drawing's stackup has been synchronized.
- Before submission, confirm that differences have been resolved. Decide whether unresolved items should block submission based on their actual impact.
- Check the mapping between exported and manufacturing layers, drills/slots, copper-to-edge clearance, and DFM issues raised by the manufacturer.
- Do not let platform defaults silently replace design requirements.
- If a process is unsupported, state the conflict and available options.

### JLC China SMT Import Format

This section applies only to the current SMT file-import flow for JLC China.
Keep the project's complete BOM records separate from the platform's required columns.

- The official required BOM fields are `Comment`, `Designator`, and `Footprint`.
- `Quantity` is recommended.
- If `Quantity` is provided, it must equal the number of valid designators in that row.
- Components with the same model, specifications, and footprint may combine designators.
- List each designator on a separate row in the coordinate file.
- If a JLC part number is provided, the platform prioritizes matching by that number.
- Resolve any conflict between the part number and component specifications first.
- Consistently exclude designators not included in this SMT assembly from both the placement BOM and coordinate file.
- Keep DNP, hand-assembly, and similar arrangements in the project's assembly records separately.
- Do not rely on custom notes to automatically convey manufacturing requirements.

Source: [JLC BOM and Coordinate Format Specification](https://www.jlc.com/portal/server_guide_48022.html).

- Check the coordinate file fields `Designator`, `Mid X`, `Mid Y`, `Layer`, and `Rotation`.
- `Mid X` and `Mid Y` use component-center coordinates.
- Check angles against the component's axis.
- Prefer `mm` for coordinate units.
- When using `mil`, identify the unit after the numeric value.
- Do not append units to the `Mid X` and `Mid Y` column names.
- Record the coordinate origin used for export.
- Use `Top`/`T` or `Bottom`/`B` for `Layer`.
- Set the side according to the side on which the component body is mounted.
- Confirm the side of special components according to their actual assembly requirements.
- The official documentation does not specify the coordinate-origin location.
- This project requires checking in the import preview that coordinates correspond to the PCB.

Source: [Coordinate Format Explained](https://www.jlc.com/portal/q7i53182.html).

For JLC prototype orders from Pro Edition, do not select bottom-layer coordinate mirroring.
Do not enable bottom-side angle mirroring without authorization either.
This setting must not be generalized to all EDA tools or all assembly manufacturers.
After import, still check bottom-side placement, rotation, and polarity item by item.
Source: [Pro Edition Coordinate Export](https://prodocs.lceda.cn/cn/pcb/export-pick-and-place-file/).

### BOM Matching and Parts Supply

- Check the matched manufacturer's complete part number, footprint, key specifications, and supplier part number item by item.
- Check matched designators, quantities, assembly side, DNP items, assembly variants, and out-of-stock items.
- Check availability, assembly support, packaging/reel or wastage requirements, and fees for the actual order quantity.
- Historical inventory and unit prices are not current commitments.
- Recheck electrical, pinout, footprint, surrounding circuitry, and manufacturing impact for platform-recommended substitutes.
- Similar names do not prove that parts are interchangeable.
- Record missing parts, self-supplied parts, customer-supplied parts, hand-assembled parts, and do-not-place parts separately.
- Confirm that the final BOM and coordinates match.

### Placement Preview

After import, compare against the PCB and footprints; check each designator's model, position, side, rotation, and polarity.
Pay particular attention to pin 1, diode direction, polarized capacitors, connector mating direction, and parts the platform may not identify reliably.

Do not substitute automatic matching or a quotation for inspection.
If an offset or rotation issue is found, first check the coordinate definition and library mapping.
Correct the corresponding file or platform entry.
Inspect the placement preview again.

### Pre-Submission Check

Confirm that the uploaded version, order processes, BOM and coordinates, matched part numbers, DNP items, placement directions, quantities, and unresolved manufacturing or material issues are consistent.
After a platform change, update the corresponding local records.
Do not continue to mark an old version as approved for production.

An unresolved real manufacturing or assembly conflict blocks the affected production submission.
List incomplete prototype tests as pending verification.

### Programming and Test Handoff

- Provide the locations, board sides, pin order, and net list for programming pads and test points.
- Specify the programmer, power method, target voltage, and any required reset or boot actions.
- Specify test items, instruments, reference ground, and acceptance ranges.
- Check that bare test pads were not mistakenly included in the assembly BOM or coordinate list.
- Check the assembled quantity and default state of 0 Ω resistors.
- If a 0 Ω resistor is removed or replaced during testing, restore it according to the plan and inspect it before delivery.
- Prototype validation includes actual programming and probe-contact checks.
